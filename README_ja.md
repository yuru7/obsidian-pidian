# Pidian

Pi Coding Agent in Obsidian

[English](README.md) | **日本語**

![icon](./assets/obsidian-pi-badge-256.png)

Obsidian のサイドバーで AI と会話し、開いているノートの質問・編集や、ノート検索、Web検索ができるプラグインです。

AI ハーネスの [Pi Coding Agent](https://pi.dev) を内蔵しているため、外部ツール不要で優れたエージェント体験ができます。

現在、Desktop のみに対応し、モバイルには非対応です。

## できること

AI エージェントの判断でノートを読み書き、検索なども自動で動作します。

- 今開いているノートや画像について質問する
- Vault 内のノートを探す
- Vault 内の PNG / JPEG / WebP 画像を読む
- ノートを編集する
- ノートの編集や Web 検索などは実行権限により動作を制限可能

## インストール

Obsidan Community Plugin からインストールしてください。

ソースからビルドする場合は [CONTRIBUTING.md](CONTRIBUTING.md) を見てください。

## クイックスタート

有効化すると、右側に Pidian のサイドバーが開きます。閉じたあとは、左のリボン、またはコマンドパレットの「Pidian を開く」からサイド開くことができます。

1. 設定 → Pidian → **API認証** で、使うサービスの API キーを入れる
2. **全般**、またはサイドバー下部でプロバイダとモデルを選ぶ
3. ノートやその他の Vault ファイルを開いた状態で、サイドバーでメッセージを書く

API キーを空欄のままにすると、環境変数を使います。

新しい会話は、サイドバーの「新しいチャット」か、コマンドの「新しい Pidian チャット」です。

## 権限

誤操作を防ぐため、最初は読み取り以外を抑えています。設定 → Pidian → **権限** で変更できます。

| 操作 | 初期値 | 内容 |
| --- | --- | --- |
| 読み取り | 常に許可 | ノートと PNG/JPEG/WebP 画像を読む、Vault を検索する、フォルダを見る、タブを開く・切り替える |
| 編集 | 毎回確認 | 既存ノートの変更。実行前に対象ファイルと差分が出ます |
| 作成 | 拒否 | 新しいノートを作る |
| 削除 | 拒否 | ノートを Obsidian のゴミ箱設定に従って捨てる |
| Web検索 | 毎回確認 | Web を検索する、ページを取得する |

「毎回確認」のときは、実行前に許可 / 拒否を聞かれます。拒否すると、その操作だけ止まります。会話自体は続きます。

ノートを作らせたい、消させたい、Web を調べさせたいときは、必要な項目だけ「毎回確認」か「常に許可」に変えてください。

編集機能は Obsidian 経由で編集するため、Obsidian 標準の Undo で戻せます。

## コンテキスト

メッセージを送った時点のアクティブなファイルのパスを渡します。Markdown ノートでは、カーソル位置または選択範囲も付けます。Canvas と PNG / JPEG / WebP 画像はパスだけです。画像の中身が必要なときは、Vision 対応モデルならエージェントが `read_image` で読みます。

## 会話の保存

会話は Vault 内のプラグイン用フォルダ（既定は `pidian/sessions/`）に保存されます。場所は設定 → Pidian → **全般** の「プラグイン用フォルダ」で変えることができます。

古い会話の自動削除をオンにすると、保持日数より古い会話を起動時に削除します。

### 追加の指示（任意）

`pidian/AGENTS.md` (プラグイン用フォルダがデフォルト値の場合) を置き、そこへ AI の口調や動き方の指示を書くと、動作をカスタマイズができます。無くても動作に問題はありません。

```markdown
# Instructions

- 日本語で回答する
- ノートの文体を維持する
- 編集前に必ず内容を確認する
```

## API キー

API キーは Obsidian のプラグインデータに保存されます。

優先順位は次のとおりです。

1. Pidian の設定
2. 環境変数

環境変数例:

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
- `GEMINI_API_KEY`
- `OPENROUTER_API_KEY`

Chat Completions 互換のエンドポイントは、設定 → Pidian → **API認証** の Custom OpenAI Compatible に Name / Base URL / Model ID / API key を追加します。画像を送れるモデルは **Vision 対応** をオンにします。既定はオフです。

## 制限事項

- Desktop only（Mobile 非対応）
- `.obsidian/` と会話ファイルは操作しません
- Pi Conding Agent の拡張機能は利用できません
